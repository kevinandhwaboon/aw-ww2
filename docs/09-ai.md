## 1. Principles

1. **An AI is a player.** It gets the game state and sends the same commands a human does, through `apply`. It has no special access to the engine and no rule exceptions.
2. **Legal by construction.** The engine rejects anything illegal, so a buggy AI can't break a game. A rejected command is an AI bug, and tests treat it as a failure.
3. **No cheating bonuses.** The first AI gets no extra funds, damage or vision. Difficulty comes later, from smarter play or commander personalities.
4. **Pluggable.** Built-in and community AIs use the same interface, as plain JS/TS modules (00-master-design §15).
5. **Fast enough for theater scale.** The Normandy map will have far more units than today's test maps, so per-unit cost must stay low (section 6).

## 2. The interface

```ts
interface AiPlayer {
  readonly name: string;
  /** The next command for the current player. Called repeatedly until it returns endTurn. */
  chooseCommand(view: AiView): Command | Promise<Command>;
}
```

- **`AiView`** gives the AI the game state with the RNG hidden and without the enemy units it can't see: submerged submarines (05-supply-transport §9, since 2026-11-14) and, with fog of war on, everything its side can't see (19-fog-of-war §8, since 2026-11-17), the player it controls, and `legalCommands()`. An AI calls the same engine helpers the UI uses (move destinations, attack and fortification targets, forecasts, capture and build checks) on that state.
- **`legalCommands`** (engine) lists every command the engine would accept right now, ending with End Turn, including Carrier launches since 2026-11-13. One simplification: an Unload lists each passenger and tile on its own, not two passengers in one action (D3). The random-playthrough tests send random picks from the same list.
- **It's asynchronous from day one**, even for the built-in AI, so an AI can later run in a Web Worker without changing the interface **(D8)**.
- **One command at a time**, so the UI can animate each move and the state is always valid between calls.
- **Who controls a player** (human or AI) is session setup, not game state. The rules engine doesn't know or care.

## 3. Rules every AI must follow

- **Don't read `state.rng`.** It would let an AI predict every luck roll. Use forecasts, which give the range. `AiView` hides the RNG value so this can't happen by accident.
- **Don't use `Math.random` for decisions.** An AI that needs variety gets its own seeded generator, so AI games replay exactly and bugs can be reproduced.
- **No hidden state between games.** Anything an AI remembers during a game should be rebuildable from the state, so saves keep working. One exception, since 2026-11-17: in fog of war Greedy remembers enemies it has seen (§4g). That memory is only a hint: if the game is reloaded it's gone, and the AI plays from what it sees, never wrongly.
- **Always finish.** An AI must reach `endTurn`. The session enforces a limit of 300 commands per turn and ends the turn if it's exceeded, logging that as an AI bug. The same happens if an AI throws an error or sends a command the engine rejects.
- **Pure code.** AI code (`src/ai/`) follows the engine's rules: no DOM, no Phaser, no `Math.random`, no clock. The same lint and type checks enforce it.
- **Where Greedy lives.** `src/ai/greedy.ts` picks each unit's command. It builds on `greedyProduction.ts` (what to build), `greedyLandings.ts` (landings, drops and carriers, §4b) and `greedyBase.ts` (shared helpers and distance maps). They are layers of one object, so each file can use the ones beneath it.

## 4. The first AI: "Greedy"

Each unit in turn picks its best-scoring action, with no lookahead and no plan across units. That's enough to be a real opponent for testing and an honest baseline to beat.

**Order of play:** units that can attack first, then capturers, then everything else, then Build, then End Turn. Within a group, the most valuable unit goes first.

**Scoring a candidate (destination plus action):**

| Candidate | Score |
|---|---|
| Attack | Value of the damage dealt, minus the value of the expected counter, using the forecast's midpoint. Large bonus for a kill |
| Capture | High, and higher for an HQ, then factories, then cities. Higher still if it finishes the capture |
| Attack a fortification | Only if it blocks the way to an objective |
| Move toward an objective | Closer to the nearest enemy property, or to the nearest enemy unit, is better |
| Retreat | At 3 HP or less, prefer an owned property that repairs this unit |
| Terrain | Small bonus per defense star at the destination |

**Value of damage** = damage % × the target unit's cost. That single rule makes the AI prefer hitting expensive units with cheap ones, without a hand-written matchup table.

**Transport and supply:** in the first version (until §4b is built), Halftracks only carry infantry toward distant objectives and resupply neighbours. Landing Craft and Transport Aircraft are left idle at first, so naval invasions by the AI aren't in the first AI **(D9)**.

**Building:** first ensure a minimum of capture-capable infantry, then spend the rest on the unit type that best counters what the enemy has fielded, scored from the damage chart. Availability and funds limit the choice as usual.

**As built (2026-11-09).** Details the table above left open, all tunable in `src/ai/weights.ts`:

- **Scores are in funds**, the same unit as costs, so an attack, a capture and a step forward compare directly. Attacks use the forecast's midpoint; a sure kill adds half the target's cost, a lucky one 15%. Hitting a unit that is capturing one of our properties adds a bonus.
- **Capture values per action:** HQ 8,000, factory 3,500, airfield and port 3,000, city 2,500. Finishing the capture adds 2,000, and a scenario objective adds 4,000.
- **Where to go:** distances count real movement points over the terrain, so a tank goes round a river instead of getting stuck on the bank. Capturers head for the nearest property not already being captured by a friend, so they spread out. Direct-fire units head for enemies they can damage. Indirect-fire units head for tiles with an enemy in range. Aircraft and ships with nothing to shoot at stay put.
- **Retreat** at 3 HP or less, when out of ammo with no second weapon, or when an aircraft or ship's fuel is within three days' burn of what it takes to get home. It heads for its own property that repairs it. (Since 2026-11-13 the fuel rule also counts the daily burn on the way home, and aircraft count Carriers with room as home: §4b.)
- **Halftracks:** infantry board one when its goal is more than two turns' walk away and the Halftrack hasn't moved yet. Halftracks act last, carry passengers toward properties and unload near them, resupply neighbours, and otherwise stay with the foot units.
- **Building:** at least 3 capture-capable units, or one per three properties still to take, up to 8. After that, every type scores (damage it deals × enemy cost − half the damage it takes × its own cost), averaged over the enemy's units and divided by the square root of its cost, which balances quality against numbers. Before the enemy fields anything, it scores against what they could build. Funds are shared out over the free production sites.
- **Submarines** never dive. Fortifications are attacked only when breaking them shortens the way to the goal by more than two movement points.

## 4a. Greedy v2, part 1: threat-aware production (built 2026-11-13)

Milestone 16. Measured before the change (seed 7, AI vs AI, 40 days): the losing side banked 47,000 to 72,000 unspent funds on Twin Bridges, Bocage Country and Proving Ground, because its own units stood on its factory, which blocks building there. On Normandy one side built 120 Torpedo Boats and the other 84, fighting each other in the Channel while the land war never started. And building only looked at the enemy's whole army, so a Bomber circling the factory counted no more than one at the far end of the map.

The new rules, all tunable in `src/ai/weights.ts`:

- **Spend on the best unit, not the cheapest.** A site builds one unit a turn whatever it costs, so among the units its share of the funds can pay for, the most valuable wins; cheap units only win when money is short (the score is divided by the square root of the larger of the unit's cost and the site's budget, not of the cost alone). Measured before: a side with one factory built 1,000 Infantry every day while 100,000 piled up.
- **Capturers.** Below the minimum of 3 capture-capable units, a land site still builds only those, but the best-scoring one rather than the cheapest. Above it, up to the wanted count (one per three properties still to take, up to 8), capture-capable units get a 1,500 bonus instead of being forced.
- **Keep production sites clear.** A unit ending its move on one of our own factories, airfields or ports loses 2,500 from its score, so it moves off unless it's retreating there for repairs, attacking from there pays clearly better, or it can't move. A freshly built unit is no exception: it steps off next turn.
- **Nearby threats count more.** When choosing what to build at a site, each enemy unit counts by how close it is: 3× when it could reach the site within 2 turns (straight-line distance, not the path, ≤ 2 × its movement + its attack range), 1× otherwise. So a Bomber near the factory makes anti-air the best buy there, and a Heavy Tank on the doorstep makes a Tank Destroyer the best buy.
- **Threats already answered count less.** Each enemy unit's weight is cut by how well our units near it can already hurt it: every one of our units that could reach it within 2 turns covers (its base damage against it × its HP) of it, and the enemy counts only for the part left uncovered. One Mobile AA (75% against a Bomber) leaves a quarter of a Bomber to answer, which can still be worth a second one; two cover it fully, and the next build answers something else. Units built earlier in the same turn count, so one turn's builds don't all answer the same threat. If our units already cover every enemy, coverage is ignored, so building doesn't stop.
- **Only reachable enemies count.** A unit type built at a site scores only against enemies it could get at from there: its movement type can travel from the site to a tile from which the enemy is in its attack range. Aircraft reach everywhere. So a port on a lake doesn't build ships against a fleet in another sea, and a factory on an island doesn't count enemy tanks on the mainland.
- **A threatened site always builds.** Normally a site builds only a unit that scores above zero. When an enemy could reach the site within 2 turns, it builds the best-scoring unit it can afford even if nothing scores well, since a unit in the way beats funds in the bank (it can also block the capture).

Unchanged: the minimum of capture-capable units comes first, and funds are still shared out over the free sites.

## 4b. Greedy v2, part 2: landings, drops and carriers (built 2026-11-13)

Lifts D9. Measured before (2026-11-13, seed 7, 40 days): on The Slot and Normandy neither side ever crossed the water, and on Iwo Jima the US Landing Craft and Carriers never moved. All numbers below are tunable in `src/ai/weights.ts`.

**Stranded units.** A land unit is stranded when its landmass holds nothing for it: no property it could take and no enemy land unit it can hurt, while some other landmass does. Enemy ships offshore don't count. Halftracks never count: they stay behind. A unit at 3 HP or less retreats for repairs first, as before.

**Landing Craft.**

- An empty craft sails to a pickup tile: the free Beach or friendly or neutral Port that costs it and the nearest stranded unit the fewest turns to reach, taken together. It waits there.
- A stranded unit heads for the nearest craft with room that stands where it can load, or for the pickup tile an empty craft is sailing to, and boards as soon as it can reach the craft. It keeps off the pickup tile itself until the craft is there.
- A craft with one passenger waits for a second while any stranded unit could reach it within 2 turns. Then it leaves.
- It sails for the Beach or Port from which its passenger has the shortest way to its goal (a property to take, or else enemy land units and properties), counting both the sailing and the walk, and unloads **both passengers in one action** (D3).
- A craft with passengers presses on while it has the fuel to land them and still get back to one of our ports. Otherwise the usual fuel rule decides (below). Pickup tiles in a port count one turn dearer than a beach, since a craft waiting in a port keeps our ships from refuelling there.

**Transport Aircraft.** The same, for foot soldiers: it waits on our own airfield, takes stranded units aboard, flies to a tile beside the passenger's goal and drops it, right onto the property when that tile is free. It only drops within one turn's walk of the goal.

**Carriers.**

- **Launch:** an aircraft takes off only to attack, and only when its best move from the Carrier is an attack worth making. Aboard, it's refuelled, rearmed and repaired free, so otherwise it stays. Launches come before any other move in the turn.
- **Sailing:** a Carrier moves or launches, not both. With aircraft aboard and nothing for them to hit, it sails to within their flying range of a target and no closer than 2 tiles less. Ending where an enemy that can hurt it could attack next turn costs 3,000.
- **Landing:** an aircraft heading home for fuel, ammo or repairs counts our Carriers with room as home, alongside airfields. An aircraft with nothing to do lands on a Carrier it can reach rather than circling.

**Fuel.** Two changes for every aircraft and ship, since part 2 sends them further from home.

- **Heading home** now counts the daily burn for the days the trip takes, not only the distance: a unit turns back once its fuel is under (distance home + (days home + 3) × daily burn). The old rule left the days out, so it fired too late on long trips.
- **The point of no return:** a move that would leave less fuel than the trip home from the new tile needs costs 5,000, so a unit doesn't step past it except for a very valuable attack. A unit that couldn't get home even from where it stands is exempt.

These help less than hoped. On The Slot over 60 days, both sides together lost 21 and 24 Torpedo Boats to empty tanks in two games before the rules, and 5 to 21 over four games after (6 or 7 with the part 1 AI, which sailed less). **Open problem:** most of those boats do turn for home in time and still run dry. The suspected cause is our own ports being occupied by freshly built ships when they arrive, but two fixes for that (moving units off production sites first, and not building where a unit is coming in) changed nothing measurable and were dropped.

**Building.**

- **Landing Craft:** a port builds one while we have more than 2 stranded units per craft we own, up to 6 craft, and the craft could reach them. **Transport Aircraft:** an airfield builds one when stranded infantry can walk to it and we have none.
- While a transport is wanted but too dear, its cost is kept back: the other sites share only what's left, so the funds build up.
- **An army to ship:** a land unit type built on a landmass with a Beach or Port counts enemies it could only reach by sea at half weight (it counted them at nothing in §4a), provided we own a Landing Craft or could build one.
- Unarmed units (Halftrack, Landing Craft, Transport Aircraft, Carrier) are never chosen by the general scoring. The AI builds transports only by the rules above, and never builds Halftracks or Carriers.

**The engine's command list** now includes every legal launch (`launchCommands`), so "listed means accepted" covers Carriers too, and the random playthroughs exercise them.

**Measured after** (40 days, seeds 1 to 5 on every map, no AI bugs in any game): 41 of 55 games end with a winner, against 43 after §4a. The difference is Contested Skies, where 2 of 5 end within 40 days, down from 4; every other map is unchanged.

- **Iwo Jima:** the US launches its Dive Bombers (9 or 10 launches a game) and ferries reinforcements from its base island (3 or 4 landings). Japan still holds out the 15 days every time.
- **The Slot:** each side makes roughly 20 to 30 landings and 7 to 21 launches a game, and islands change hands (typically 8 properties against 17 by day 40, where before it stayed 10 against 10). No game on seeds 1 to 5 ends within 40 days. Run to 80 days on seeds 1 to 5 and 7, four of six end (days 34, 48, 54 and 64). The two sides together lose 21 to 32 Landing Craft in combat over 60 days, about half of them with troops aboard.
- **Normandy:** the Allies build Landing Craft and Transport Aircraft and land a few squads, but German ships sink most craft in the Channel. No winner by day 40.

So the planned test, "every built-in map ends with a winner within 40 days", is **not met** for The Slot and Normandy. What's missing is in §8:

- **Massed landings.** Craft leave two units at a time, and on the enemy's home island the factory replaces losses as fast as they arrive.
- **Escorts.** Craft sail alone through enemy Torpedo Boats and Destroyers.
- **Garrisons.** Every stranded unit leaves, so a home island can be left empty.
- **Fuel at sea.** Ships still run dry in numbers (above).

## 4c. Greedy v3: coordination, fuel and difficulty (milestone 17, built 2026-11-13)

Asked for by the developer on 2026-11-13: everything left open in §4b and §8 except commander personalities. Every part is switched by a weight in `src/ai/weights.ts`, so the AI with a part turned off can play the AI with it on. That is how each number below was measured, and "Easy" is the same AI with parts turned off.

**Focus fire and a look ahead** (all units).

- **Artillery first.** Indirect-fire units with a target shoot before direct-fire units move in, so targets are softened before anyone takes a counter-attack. (Before, the most valuable attacker went first.)
- **Focus fire.** An attack that doesn't kill is worth a quarter of the target's cost more when our other units that haven't acted yet could finish it off this turn, by a rough estimate from the damage chart, their HP and their reach.
- **The look ahead.** Where a unit ends its move, the damage the enemy could do to it there next turn counts against the move: the two hardest hits among the enemy units that could fire on that tile (using the engine's own threat ranges), as a share of the unit's value, times 0.1. A Landing Craft or Transport Aircraft carrying passengers to their landing ignores it.
- **Pressing.** The look ahead is switched off once our army is worth twice the enemy's (units at their present HP, with passengers). Without this, a side far ahead hung back for good: on Beachhead, 2 of 5 games had no winner by day 80; with it, all five end by day 28.
- **Why only 0.1.** At 0.5 the look ahead wins far more (22 games to 7 against the AI without it), but two AIs that both have it never close with each other: 25 of 36 games had no winner by day 40. At 0.1 it still wins 17 to 10 and games finish. Applying it only to units that can't fight back was tried and was worse: artillery never moved into firing range.

**Massed, escorted landings.**

- **Waves.** A loaded Landing Craft still at its boarding tile waits while another of our craft within 8 tiles is still loading (it has room, and either passengers are close or it's an empty craft one move from its pickup). It leaves once 3 craft are ready, or nobody nearby is still loading.
- **Escorts.** Each loaded craft on its way takes the 2 nearest warships with it: an escort sails for the craft's landing unless it has something to shoot within two turns.
- **Garrison.** The 2 land units nearest our HQ on its landmass never count as stranded, so they stay. Only when some enemy has, or could build, a Landing Craft or Transport Aircraft.
- **A bug from §4b found on the way:** an empty craft would not enter our own port to collect troops, because of §4a's penalty for standing on a production site. It sat one tile outside for days. A craft going to its pickup tile is now exempt.

**Fuel.** The open problem from §4b, traced boat by boat. The boats weren't failing to get home; most never tried:

- **Attacks beat the penalty.** Hitting a 16,000 Destroyer scores more than the 5,000 penalty for passing the point of no return, so a boat attacked, was stranded, and sank a day or two later. The penalty is now what's really lost, the unit's own value (its cost at its present HP, with its passengers), or 5,000 if that's more.
- **A reserve.** The point of no return keeps 2 days' burn in hand, since the way home may be blocked or the port taken on arrival. A move that brings a unit nearer home is never penalized, whatever its fuel.
- **Transports.** A loaded Landing Craft or Transport Aircraft that is nearer its landing than its home, and has the fuel to reach the landing, lands its passengers even if it can't get back afterwards. Before, a craft three tiles off the Normandy beach turned for England to refuel and sank on the way with its troops. And a Transport Aircraft doesn't load, and isn't built, for a drop it couldn't fly to and back from on a full tank: before, it took off for targets out of range and crashed with its passengers.
- **Ports kept free.** A port or airfield isn't built on while one of our units is coming in to it for fuel, ammo or repairs and is within two turns; and a port or airfield one of our own units stands on still counts as home for the others.

**Difficulty.** The map select screen has an "Easy computer opponent" box, and the URL takes `?level=easy`. Normal is the default. Easy is the same AI under the same rules with no handicap for either side: no focus fire, look ahead, artillery-first, waves, escorts or garrison; nearby threats don't count extra when it builds; and it counts only half of the damage it will take back when it attacks. One level applies to every computer player in the game.

**Measured** (2026-11-13; "old" is this AI with every §4c part off):

- **New against old** (6 land and coast maps, 3 seeds, both seats, 40 days, 36 games): new wins 22, old wins 8, 6 unfinished. On Twin Bridges the new AI wins all six, from either side.
- **Normal against Easy** (same 36 games): Normal wins 21, Easy wins 7, 8 unfinished.
- **The Slot, AI vs AI:** all six games (seeds 1 to 5 and 7) end with a winner by day 80, on days 29 to 54; before, four of six did, on days 34 to 64. Within 40 days, 2 of 5 end (none before).
- **Ships and craft lost on The Slot** (both sides together, 60 days, four seeds): 5 to 10 Torpedo Boats to empty tanks (5 to 21 before); 14 to 17 Landing Craft in combat (21 to 32 before).
- **Iwo Jima:** the US lands 4 or 5 full craft in the 15 days (3 or 4 landings before, mostly half-loads) and launches 7 or 8 strikes. Japan still holds out every time.
- **Normandy:** the Allies make 1 to 7 landings and 1 to 3 air drops in 40 days and take up to 4 German properties. No winner by day 40.
- **All maps, AI vs AI, 40 days, seeds 1 to 5:** 35 of 55 games end with a winner, against 41 after §4b, with no AI bugs. Two more careful AIs take longer to beat each other: Twin Bridges 2 of 5 (5 before, though all five end by day 64), Narrow Sea 0 of 5 (4 before), Contested Skies 1 of 5 (2 before); The Slot 2 of 5 (0 before); the rest unchanged. Slowest thinking: 13 ms per command, on Normandy.

**Open: Narrow Sea stalls.** Four of five games there have no winner even by day 80. One side ends up with about 58 Artillery and Mortar Teams and 3 Infantry on a 16 × 11 map: it can't capture anything and the map is too full to move. That is the building rule (§4a) choosing one unit type over and over, not the look ahead; it needs a rule for a mixed army.

**Not done:** escorts don't wait for their craft or clear the way ahead; waves form only where craft load side by side; and the AI still doesn't plan more than the one enemy turn ahead. Commander personalities were left out on purpose.

## 4d. Greedy v4: a mixed army and guarded objectives (milestone 18, built 2026-11-15)

Asked for by the developer on 2026-11-15, as the next step without commander personalities. Measured first on the maps that ship now (AI vs AI, 40 days, seeds 1 and 2):

- **One unit type over and over.** On Kursk each side built 42 to 66 Assault Infantry and 24 to 37 Mobile AA, and no Medium Tanks at all; on Bastogne the US built 29 Artillery and Germany 33 to 39 Assault Infantry with 20 to 25 Mobile AA. The building rule (§4a) scores each type on its own, so the best scorer wins every day.
- **Objectives left empty.** On Midway the US AI shipped the Marines off the atoll (they had "nothing to do" there, §4b), and Japan took both objectives by day 7 to 10.

Each part below is a weight in `src/ai/weights.ts`, so the AI with a part off can play the AI with it on.

**A mixed army.**

- **Saturation.** A unit type's building score is marked down by the share of our units of that kind (land, air or naval, passengers included) that are already that type: with a quarter of the land army Tank Destroyers, another one is worth three quarters as much. This is the rule that adds strength: alone it wins 7 games to 3 against the AI without it (Twin Bridges and Bocage Country, 16 games). Doubling or tripling it was no better (5 to 7, and 7 to 8).
- **Less shy of expensive units.** The damage the enemy would do to a unit counted against building it at half weight (`buildRisk` 0.5), which favoured cheap infantry. At a quarter it wins 8 to 4; at nothing it loses 4 to 10. It is now 0.25.
- **Artillery cap.** No more indirect fire (Mortar Team, Artillery, Rocket Artillery, Flak Gun) is built once it is a third of our land units, unless nothing else can be built.
- **Infantry floor.** The minimum of capture-capable units (§4a) was 3; it is now 3 or a quarter of our land units, whichever is more. Below it, a land site builds only those.
- The cap and the floor are neutral head to head (6 to 6 each). They are there so a large army can still take ground, which is what stalled Narrow Sea (§4c).

**Guarded objectives.** An objective we have to keep is a property we own that the other side wins by capturing (`captureProperties`), or that our side wins by holding (`holdProperties`).

- **The defenders stay.** Land units on such a property's landmass never count as stranded (§4b), so they don't board a transport.
- **One stands on it.** The nearest of them goes to the property and stays there, since a property with a unit on it can't be captured. It still attacks whatever comes next to it, but it doesn't leave.
- **Not on airfields or ports.** Nobody is posted on an objective that services aircraft or ships, or our own couldn't refuel there. The defenders stay on the landmass all the same.
- The HQ is not posted this way: its garrison of two stays near it (§4c).

**Transports refuel.** Traced on The Slot: Landing Craft shuttled from beach to beach and never entered a port, even one tile away. One loaded up with 5 fuel left and sank with both passengers.

- A loaded transport without the fuel for its trip goes home to refuel first, but only when a full tank, less the way back out, is clearly more than it has: so one that set out on a full tank keeps going.
- An empty transport under half a tank refuels before it goes to collect anyone.

**Easy** (§4c) has none of this: it builds the best scorer over and over with the old `buildRisk`, and doesn't guard objectives. It does refuel its transports.

**Measured** (2026-11-15; "old" is this AI with every §4d part off):

- **New against old** (Twin Bridges, Bocage Country and Bastogne; seeds 1 to 4, both seats, 40 days; 24 games): new wins 11, old wins 5, 8 unfinished. Of the unfinished, new holds more properties in 6 and old in 1.
- **Normal against Easy** (same 24 games): Normal wins 12, Easy wins 4, 8 unfinished, Normal ahead on properties in 7 of them.
- **Midway, AI vs AI** (seeds 1 to 3): before, Japan took both objectives on days 7, 8 and 10. Now it takes them on days 10 and 11, and in the third game the US holds the atoll to the day limit and wins. Japan's battleships and bombers still kill the defenders before it lands, which is how the scenario is weighted.
- **Landing Craft lost to empty tanks on The Slot** (both sides together, 60 days, four seeds): 0 or 1 a game, against 4 to 11.
- **What gets built** (Bastogne, seed 1, 40 days): the US builds 14 Medium Tanks and 4 Light Tanks, against 4 and 0 before, and 19 Artillery against 29. On Kursk, Medium and Light Tanks appear (6 and 3 for one side, 13 Light for the other, against none), beside 30 to 52 Assault Infantry and 19 to 39 Mobile AA.
- **No AI bugs** in any game. Slowest thinking: 19 ms per command, on Kursk.

**Not done.** The mix is better but not what a player would call balanced: on Kursk both sides still build a great many Assault Infantry and Mobile AA, because by the damage chart and prices those really are the best buys against each other. That is a question for unit balance (01-units, 03-combat) more than for the AI.

## 4e. Major Bridges (built 2026-11-15)

For Market Garden (17-scenarios-market-garden), Greedy learns to blow and rebuild Major Bridges (02-terrain §4a). A first rule, by straight-line distance, which is cheap:

- **Blow** a Major Bridge the Assault Infantry can reach this turn when an enemy vehicle (tracks or wheels) could reach it next turn and none of our vehicles is within two turns of it. Soldiers can wade a Blown Bridge, so only vehicles count. Worth `blowBridge` (6,000).
- **Rebuild** a Blown Bridge when one of our vehicles is within two turns of it and no enemy vehicle is nearer to it than our nearest. Worth `rebuildBridge` (3,000) per action.
- Easy plays by the same rule. Allies count as "ours" for both.
- Measured on Market Garden, AI vs AI, seeds 1 to 4: every game ends at the start of day 12 with a German win, with no engine problems. The Allied AI doesn't yet coordinate the drops with XXX Corps; balance for human players is untested.

## 4f. Supply Ships (built 2026-11-16)

Greedy builds and sails the Supply Ship (05-supply-transport §3a). Easy plays by the same rules.

- **Building:** a free port builds a Supply Ship, ahead of any armed unit, when we have fewer than one for every `warshipsPerSupplyShip` (4) armed ships, up to `maxSupplyShips` (2). Not while a ship of ours is coming in to that port for service (§4c).
- **Where it goes:** to the nearest free sea square next to one of our units that needs it: a ship at or under `supplyFuelShare` (60%) of a full tank, short of ammo or damaged, or a land unit on the shore that is nearly out of fuel (a quarter of a tank) or out of ammo. With nobody in need it keeps company with our warships, so it's at hand when they need it. It uses the Supply action when that refills someone (`supplyPerUnit` per unit, as for the Halftrack), and the look ahead (§4c) keeps it out of the enemy's reach like any unit.
- **Ships come to it:** for one of our ships, the free squares next to our Supply Ships count as home, alongside our ports (§4b, §4c). A ship heading home for fuel, ammo or repairs goes to whichever is nearest, and the point-of-no-return check (§4c) measures the way back to it too. Only Supply Ships with supplies left count (05-supply-transport §3b, since 2026-11-16).
- **Refilling (since 2026-11-16):** a Supply Ship out of supplies sails back to the nearest of our ports to refill, rather than to another Supply Ship, which can't refill it (05-supply-transport §3b). Ships that run dry are stranded rather than sunk now (§7), but the fuel margins of §4c are unchanged: a stranded ship is still lost to the fight.
- **Rescue first (since 2026-11-22):** a stranded ship loses 1 HP a day until it sinks (05-supply-transport §7), so a Supply Ship with supplies sails to one of our ships already at 0 fuel before any ship that is only low, as long as it can reach one.
- **Measured** on Guadalcanal (14-scenarios-pacific §4), AI vs AI, seeds 1 to 10 to day 20: both sides use their Supply Ships; the US builds a new one at its base when the first is sunk off Lunga Point. Every game ends on day 15 with a US win, with no engine problems. On The Slot and Midway, where it can now be built too, results with seeds 1 to 3 are the same as without it.

## 4g. Fog of war (built 2026-11-17)

With fog of war on (19-fog-of-war), Greedy sees only what its side sees, like a player (§3). Two changes make it play less blind. Neither applies without fog, so games without fog play exactly as before.

- **Memory** (`src/ai/memory.ts`): each Greedy player keeps every enemy unit where it last saw it, for `memoryDays` (1) days, and plans as if it were still there: it heads for it, keeps clear of its reach and builds against it. A remembered unit is forgotten once the AI can see its tile and it isn't there. It's only ever on a tile the AI can't see into, so the engine treats it as hidden: the AI never tries to attack it, and every command it sends is accepted. Easy remembers nothing (`memoryDays` 0).
- **Patrols:** an armed aircraft or ship with no enemy in sight (or remembered) that it could fight heads for the enemy's properties, and the squares next to them, that it can't see, instead of waiting where it is (`patrolInFog`). Fuel rules (§4c) still send it home in time.
- **Measured** (new Greedy against the version without these, fog on, both seats, 60 days): on Twin Bridges, the fair test map, the new one wins 10 of 12 games (1 lost, 1 unfinished); on Guadalcanal 6 of 12. Patrols alone changed nothing on either map (4 of 8 each); the gain is the memory. Remembering for 1 day did better than 2 or 3 (Twin Bridges 7 of 8 against 6 of 8, seeds 1 to 4), and remembering only land units made no difference. On the battle maps the map decides: Midway, Iwo Jima, Market Garden and El Alamein go to the same side whichever version plays it (3 of 6 each, seeds 1 to 3), and The Slot has no winner by day 80 either way. No AI bugs in any of these games, and fog self-play on every map (seeds 1 and 2, 30 days) finds no problems.
- **Scouting** (added the same day): Greedy keeps `scoutsInFog` (1) scout, a land unit that sees at least `scoutMinVision` (4) squares, which today means a Recon. With none, it builds the cheapest one at the first factory that can, ahead of other armed units, once it has its minimum of capture-capable units. The scout heads for the edge of what its side can see: the squares just out of sight, next to ones in sight, that are nearer the enemy's properties than it is now, so the edge moves on ahead of it. It still takes a good shot on the way, and the look ahead (§4c) keeps it out of reach of enemies it knows of. Easy keeps no scout. A unit only counts an enemy as within reach for the order of play (§4c) when it can see it, since one it only remembers can't be attacked.
- **Measured** (fog on, both seats, 60 days, Twin Bridges seeds 1 to 10): with scouting against without it (memory and patrols in both), 17 of 20 games won and 3 lost; against the version with none of §4g, 14 won and 6 lost. On Guadalcanal, Bastogne, El Alamein and Market Garden (seeds 1 to 3) the map decides, as before (12 won, 11 lost, 1 unfinished).
- **Tried and dropped: spotting.** A bonus for moving a unit to where it brings a remembered enemy into view, when another of ours could then attack it, with those spotters moving first: on Twin Bridges it lost 6 of 20 games to 14 against the same AI without it. Without moving spotters first, or with a smaller bonus, it made no difference (10 against 9). A penalty for paths through a remembered enemy's square, a likely ambush, made no difference either (10 against 9). Neither is in the code. Greedy still walks into ambushes in Forest and Bocage, and only attacks a unit hidden there once something has come next to it.

## 4h. Steady pressure from the sea (built 2026-11-17)

Reported by the developer on 2026-11-17: on the naval maps the computer lands one wave, and once that's beaten no more threat comes, even when the objective is on that island. Traced (AI vs AI, seed 1):

- **Midway:** Japan lands its three craft on day 3. They're then too low on fuel to get home and drift until they're dry, while 7 to 9 fresh squads wait on Japan's home island for the rest of the game.
- **Guadalcanal:** the two craft land their troops on side islands, not at Henderson Field, and are sunk by day 9. From then on 12 squads wait at home and Japan holds 11,100 in funds, but it buys Torpedo Boats and never another craft.

Three causes, each fixed:

- **Spent craft.** An empty Landing Craft or Transport Aircraft under half a tank that can't get back to a port or airfield (or a Supply Ship, for a craft) to refuel is spent. It doesn't count as one of our craft when deciding whether to build another (§4b), and no one boards it or waits for it, so troops don't climb aboard a craft with 1 fuel and sit there for good.
- **Funds kept back mean kept back.** While a transport is wanted but too dear, its cost is kept back from the other sites (§4b). Before, each site could still buy one unit of its cheapest type out of those funds, so the saving never added up. And a port one of our own ships stands on for the moment, in for fuel, still counts as the place the craft will be built, so the funds stay kept back.
- **Landings aim at the objective** (`landOnObjectives`). When our side wins by capturing properties (`captureProperties`, and since §4i also `holdProperties`), every Landing Craft and Transport Aircraft carries its troops to where they can get at those properties, if one is on a landmass a craft can put them ashore on. Otherwise they go for the nearest property to take, as before. Easy does the same.

**Measured** (AI vs AI, seeds 1 to 5, before and after):

- **Guadalcanal** (20 days): Japan lands 1 or 2 squads next to Henderson Field after the first wave, where before it landed none there: its later landings all went to side islands. It builds 1 or 2 craft a game (0 or 1 before). The US AI's fleet sinks most of them on the way, so the US still holds every game.
- **Midway** (20 days): every Japanese craft lands its troops, 6 squads against 4. Japan can't afford a second craft within the 12 days (income about 1,000 a day against 12,000 a craft), so the battle is still decided by the first wave and the carriers.
- **Iwo Jima** (20 days): the US lands 13 to 18 squads next to its objectives (8 to 11 before). Japan still holds out every time.
- **The Slot** (40 days, seeds 1 to 4): one game ends with a winner (none before); landings about the same.
- **Normandy** (30 days, seeds 1 to 3): the Allies build 11 to 13 craft (7 to 9 before) and land about as many squads; German ships sink most craft in the Channel.

**Not done:** craft that have landed their troops far from home still can't get back to fetch more, so on long crossings every craft is used once. Loaded craft still ignore the danger on the way (§4c), so a strong enemy fleet sinks the later craft one at a time.

## 4i. The pull of the objectives (built 2026-11-17)

Asked for by the developer on 2026-11-17, as a cheap step toward planning: every land unit also drifts toward the scenario's objectives, not only toward the nearest thing it can take or hit.

- **The pull** (`objectivePull`, 60): a land unit's move scores 60 for each step it brings the unit nearer the nearest objective our side has yet to take that it could walk to, and loses 60 for each step away. That's half of `advancePerStep` (120), so it breaks near ties without overriding a unit's own goal, an attack or a capture. Transports, aircraft, ships, guards on their posts and units heading for a ride are left alone.
- **Objectives** are the properties our side wins by capturing or by holding (`captureProperties`, `holdProperties`) that our side doesn't hold yet. Landings (§4h) now aim at both kinds too; before, only captures.
- **No pull** on maps won only by taking the HQ: play there is exactly as before. Easy has the pull too.

**Measured** (AI vs AI, both sides with or without the pull, 30 days; seeds 1 to 16 on Iwo Jima, Guadalcanal, Market Garden and Midway, 1 to 6 on El Alamein). Per game, "near" counts the days × objectives with an attacking land unit within 2 squares; "held" counts the days × objectives the attacker holds:

| Map | Near, without → with | Held, without → with |
|---|---|---|
| Iwo Jima | 5.7 → 7.0 | 0.9 → 0.6 |
| Guadalcanal | 2.9 → 3.9 | 0 → 0 |
| Market Garden | 9.0 → 10.0 | 3.2 → 6.2 |
| Midway | 8.1 → 7.8 | 5.7 → 5.8 |
| El Alamein | 0 → 0 | 0 → 0 |

No game changed winner: these battle maps are decided by how each scenario is weighted, not by which way the attacker walks.

**Tried and dropped:**

- **A stronger pull.** At 150, 200 or 500 the attacker gets no nearer on Iwo Jima or Guadalcanal, and Market Garden gets worse: the Allies hold their bridges 0 days instead of 3 to 6, because troops leave a bridge they hold to walk at the next one.
- **Urgency**, a pull that grows toward the enemy's deadline (`surviveDays`), up to twice or four times as strong on the last day: no better at twice, and Market Garden worse at four times (1.3 days held against 6.3). Not in the code.

**What it shows:** direction isn't what the attacker lacks on these maps; strength at the point of contact is. The next gains need the planning layer (§8): massing units before they go in, and roles such as assault, screen and garrison.

## 4j. Supply posts: a Halftrack for the Railway Gun (built 2026-11-19)

Reported by the developer on 2026-11-19: the computer doesn't resupply the Gustav. An empty Halftrack's only job was to stay with our foot units, so the one starting beside the Railway Gun at Sevastopol drove off to the infantry. The gun can't drive to a property to rearm (it runs only on track), so it fired its 3 shells and was silent for the rest of the game.

- **Who gets one:** each of our armed land units that **can't stand on any property**, so no property can ever rearm it. Today that's only the Railway Gun (01-units §2b); ordinary units far from a town are left alone, and Halftracks keep their old jobs there.
- **Which Halftrack:** the nearest of our empty Halftracks that can drive to a square beside it, one per such unit. A Halftrack with passengers keeps carrying them.
- **What it does:** it drives to a free square beside its charge, off the track if it can so it never stands in the gun's way, and stays there whether the gun is full or not. It rearms the gun automatically at the start of our turn, and with the Supply action when that helps (`supplyPerUnit`, as before). When the gun moves down the line, the Halftrack follows.
- **Measured** (AI vs AI on Sevastopol, seeds 1 to 5, to day 15): the German Railway Gun fired exactly 3 times in every game before; now it fires 6 to 9 times. Germany won 2 of 5 before and 3 of 5 now; the other games were undecided by day 15.
- **Not done:** the Halftrack doesn't keep out of danger to stay at its post, and the Railway Gun doesn't wait for its Halftrack before moving.

## 4k. Map plans: an AI for one map (built 2026-11-20)

For the Campaign (22-campaign §6), a map can have its own AI: Greedy with a **map plan**, a small object Greedy consults while it scores (`src/ai/mapPlan.ts`, plans in `src/ai/maps/`). It's still a player under §1 and §3: commands go through the engine, and the plan sees only the state the AI sees, with remembered enemies (§4g) and each side's losses.

- **Goals:** a plan can name where a unit should head instead of its usual goal. A unit that should go home first (low fuel or ammo, badly hurt) still does.
- **Attack bonus:** a plan can add to an attack's score, or forbid it (-∞). Launches follow, since an aircraft only takes off to attack when the attack scores above zero.
- **Scouts:** an aircraft aboard a Carrier that the plan gives goals takes off toward them with nothing to attack, once no attack launch is left (Greedy alone launches only to attack, §4b).
- **Hints:** a plan can keep a hint between commands (where it has searched), like the memory of enemies: lost on reload, never needed to play legally.
- **Squares to keep off:** a plan can name squares a unit shouldn't end its move on (an objective a unit that can't capture would only block); scored like blocking one of our own production sites.
- **Where used:** only in the Campaign, so Skirmish balance is unchanged (the developer's choice, 2026-11-20). Plans so far: Midway (22-campaign §6a; AI vs AI on the campaign setup it took Japan from winning 2 of 8 to 8 of 16 before any extra units), the Battle of Britain (§6c), Gazala (§6d), and the simple "drive on the objective" plan on Ten-Go (§6b).

## 4l. Spending: one site kept per ship or aircraft coming home (built 2026-11-20)

Found while tuning the Campaign (22-campaign §5a), agreed with the developer as a fix for every game: an airfield or port within two turns of any aircraft or ship heading home was kept free (§4c), so in a busy air war every airfield was kept free at once and nothing was built. On the Battle of Britain the computer's Germany ended turns with more and more unspent, up to 111,950 by day 14 in the Campaign.

- **Now each one heading home keeps only the nearest free site of its kind** that it could reach within two turns, one site each; the other sites build as usual.
- **Measured:** on the Battle of Britain (seed 3), Germany's funds left at the end of its turn now stay mostly under 8,000 in Skirmish after day 7 (before: 5,000 to 26,800), and grow more slowly in the Campaign. There the limit is now real: Germany has more aircraft than airfields, and its only factory is often taken by its own units, so extra money can't become units. The Battle of Britain's campaign AI deals with that (22-campaign §6c).
- The Slot AI vs AI test now plays two games (seeds 7 and 1): seed 7 no longer has a capture by day 25, though over seeds 1 to 5 properties change hands 15 times against 12 before.
- **Skirmish after the change** (seeds 1 to 8, 40 days): every map that finishes has the same winners as before (the Battle of Britain, Gazala and Guadalcanal the Allies 8 of 8; Iwo Jima, El Alamein and Market Garden the Axis 8 of 8; Sevastopol 4 and 4; Midway the US 6, Japan 2; Ten-Go the US 7, Japan 1), and most of those games are move for move the same, since the change only matters when several units are coming home at once. Stalingrad: the Soviet Union wins 4 of 8 by day 40, the others undecided. Kursk, Normandy, The Slot and Bastogne mostly don't finish by day 40, as before.

## 5. In the UI

- In the Campaign (22-campaign §3) the computer always plays every Axis player, at Normal, with the mission's map plan if it has one (§4k). The rest of this section is Skirmish.
- A human vs AI game is chosen on the map select screen, per player: a "Computer plays …" box for each. By default the computer plays every player who isn't on the first player's side (decided 2026-11-15, at the developer's request, for Market Garden, where the US and the UK are both Allies; built the same day). Until then it was everyone but the first player, which is the same on every map with one player per side. So on Market Garden one person plays both the US and the UK against a computer Germany, and the boxes still allow any mix, such as two people playing co-op. The URL can say who it plays: `?ai=1`, `?ai=0,1` (watch AI vs AI) or `?ai=none`.
- An "Easy computer opponent" box on the same screen sets the level for every computer player (§4c); `?level=easy` in the URL does the same.
- During an AI turn, input is locked and its commands animate like a human's, with a short pause between units. A speed option can come later.
- The pass-the-device screen is skipped for AI players, and shown only when two or more people play.
- During an AI turn you can still move the cursor and peek at units, but not give orders, end the turn or undo.
- The debug panel's event log shows what the AI did.

## 6. Performance

- Target: an AI turn on today's maps feels instant apart from animation, and thinking takes under 100 ms per unit. Measured on 2026-11-09: under 1 ms per command on the small maps, about 8 ms on Normandy. A test keeps it under 100 ms.
- Reachable tiles are already bounded by each unit's move points, so cost grows with unit count, not map area.
- Scoring must avoid comparing every unit with every other unit on theater maps. Group enemies by area if that becomes a problem. This is measured, not guessed: a benchmark test will track it.

## 7. Testing

- AI vs AI games, using the random-playthrough invariants already in the test suite.
- Every command the AI sends is accepted.
- Games between AIs finish within 40 days on every built-in map where the sides can reach each other by land. On the maps that need landings (D9), AIs play 10 days without an AI bug. Measured on 2026-11-09: Twin Bridges, Bocage Country, Crossroads, Bastogne, Iwo Jima and Proving Ground all end with a winner; Narrow Sea, Beachhead, Normandy and Contested Skies stall. Measured again on 2026-11-13, 40 days, seeds 1 to 5 on every map: before §4a, 38 of 55 games ended with a winner (Narrow Sea, Normandy and The Slot never; Twin Bridges 3 of 5); after §4a, 43 of 55 (Narrow Sea 4 of 5, Twin Bridges 5 of 5, Contested Skies 4 of 5; Normandy and The Slot still never, as they need §4b). No AI bugs in any game. After §4b: 41 of 55; see §4b for Contested Skies, The Slot and Normandy. After §4c: 35 of 55, since two more careful AIs take longer to beat each other; all six Slot games end by day 80, and Narrow Sea stalls (§4c).
- Since 2026-11-14 only the battle maps ship (00-master-design §8). AI vs AI games must end with a winner within 40 days on Iwo Jima, Midway and (since 2026-11-16) Guadalcanal, whose day limits end every game; Normandy, The Slot, Bastogne and Kursk play 10 days without an AI bug. Since Bastogne became plain defeat (2026-11-14, 13-scenarios-ardennes), AI games there run long: measured with seeds 1, 2, 3 and 7, two end on days 59 and 71 and two have no winner by day 80, all with no AI bugs. Iwo Jima and Midway are lopsided by design (Japan wins both, whoever plays them), so "Normal beats Easy" is measured on a fair test map kept only for the tests, Twin Bridges, in `tests/fixtures/maps/`: Normal must win at least 6 of 8 games (seeds 1 to 4, both seats, 60 days). Bocage Country was dropped from that test and from the fixtures on 2026-11-15: the same seat wins it whichever AI plays.
- Spot tests: it takes a free kill, it captures an undefended HQ, it doesn't attack when the trade is clearly bad.
- Same seed, same game: AI vs AI replays exactly.
- **Self-play harness** (added 2026-11-15, `src/ai/selfplay.ts`). `selfPlay` plays a game like `playMatch` and checks the engine as it goes: after every command the state must pass the state checker (`src/ai/invariants.ts`: no two units on a tile, unique ids, HP, fuel, ammo and funds in range, transports within capacity and carrying only what they can, capture progress only under a capturing unit, no game left running with one side), at the start of every turn the game must survive saving and loading unchanged, and with the deep option every command the engine lists as legal must be accepted. An AI bug is recorded and the game goes on; an engine problem stops the game and is reported with its day, player and command number. A **Random AI** (`randomAi`, any legal command, its own seed) reaches states the Greedy AI never would. The test suite plays 3 days of deep random play on every built-in map.
- **Batch runs:** `npm run selfplay` plays many seeded games outside the test suite and prints, per map, how many ended, who won and when, and any problems. Options: `--maps a,b`, `--seeds 1-20`, `--days 40`, `--players greedy|easy|random`, `--deep`, `--campaign` (the campaign missions, with the Allies as `--players` and the Axis as the campaign's computer, advantage and map plan included; 22-campaign §5), and `--commanders` (every player under a commander of their side, picked by the seed; 06-commanders §6), and `--fog` (fog of war on, 19-fog-of-war). Each game with a problem is saved in `selfplay-failures/` (not committed) with its map, seed and commands, enough to replay it exactly and turn it into a test. The run exits with an error if any game had a problem.
